scanСканер системы

Анализирует Temp, Prefetch, Amcache, кэш браузеров и логи. Показывает размер каждой категории — выбираешь что удалить.

usnUSN Journal

Удаление и пересоздание NTFS журнала изменений. Убирает историю файловых операций.

tracksОчистка следов

Shellbag, Prefetch, Amcache, Minidump, Jump Lists, Recent Files — всё одной кнопкой.

memoryПамять javaw

Сканирование и зануление строк в памяти процессов javaw.exe через Windows API.

privacyПриватность

Буфер обмена, кэш иконок, история поиска Windows, история диалога «Выполнить».

netСетевые операции

Flush DNS, сброс Winsock/TCP-IP, очистка ARP таблицы и NetBIOS кэша.

sysСистемная очистка

Реестр (MUICache, UserAssist), дампы памяти, кэш Windows Update, thumbnail кэш.

globalГлобальная очистка

Event Log, MFT, Amcache, Jump Lists, Recent Files, Browser History, Temp — за один запуск.
